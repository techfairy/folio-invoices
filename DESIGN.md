# Folio interface

Operate mode. A document workspace used by one freelancer on a laptop and phone in ordinary daylight. Off-white canvas, white document sheets, dark graphite text, restrained forest-green actions and paid states. System sans-serif, tabular monetary values, fixed rem type scale, 16px body. No illustrative dashboards or invented financial data.

Desktop: 224px navigation rail, content with clear page heading and create action; invoice history uses a real table. The editor presents a form beside a document preview. On phones navigation becomes a compact top bar, tables become labelled rows and editor/preview stack. Every field has a visible label, keyboard focus and validation. Common spacing tokens: 4, 8, 12, 16, 24, 32, 48px; adjacent same-background sections share one gap.

PDFs use white A4, Noto Sans for Latin/Cyrillic and currency characters, graphite table headings, discreet green paid marking. Multi-page tables repeat their headings. The preview and PDF use the same monetary calculations. Pending, empty, error and local-only states stay explicit.
